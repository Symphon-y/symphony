# Root-owned system files: the single source of truth for install/sync-system.
#
# Format: <mode> <source, relative to system/> <absolute target>
#
# Targets are root-owned copies, never symlinks: a link into this user-owned
# repository would let the user account (or an agent acting as it) change system
# configuration without sudo.
#
# Machine-specific files live in system/hosts/<hostname>/files.txt, in the same format
# with sources relative to that host's directory. They are added when the target's
# /etc/hostname names that host.
#
# A mode of "-" means the target filesystem has no per-file Unix permissions. The ESP
# is vfat: its files' modes come from its mount options (fmask/dmask=0077, checked by
# the Phase 1 acceptance tests), so no mode is checked or set for them.
